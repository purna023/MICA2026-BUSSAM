# MICA2026 – BUSSAM Prompt-Robustness Study

## Overview

This repository contains the implementation and experimental setup for a reproducible study based on the BUSSAM breast ultrasound image segmentation framework.

The project focuses on studying the robustness and reproducibility of BUSSAM under controlled prompt variations and evaluation settings.

The repository includes the BUSSAM source implementation, supporting utilities, configuration files, and experiment-related documentation.

## Objectives

- Study the robustness of BUSSAM under different prompt conditions.
- Improve experimental reproducibility.
- Audit dataset splits for possible duplication or leakage.
- Evaluate segmentation performance using standard metrics.
- Generate consistent and reproducible experimental results.
